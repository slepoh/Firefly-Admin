      📌 项目介绍

      Firefly-Admin 是 Firefly 博客（Slepoh/Firefly）的可视化管理后台：通过 GitHub API 远程增删改文章、动态、单页与图库素材，在线编辑全部站点配置文件，保存即提交到 GitHub，由 Cloudflare 自动重新部署，无需服务器与构建。

      • 文章内容 — Markdown / MDX 结构化编辑，支持子目录分类
      • 我的动态 — 时间线式动态发布，自动按时间命名
      • 页面信息 — 关于 / 友链 / 留言等单页管理
      • 图库素材 — 图片资源集中浏览、上传与管理
      • 基础 / 功能 / 页面 / 扩展配置 — 站点全部配置在线可视化编辑。同时支持高级版配置，可通过查看源代码进行修改。

      💾 数据备份

      一键打包博客仓库 src/config/ 下全部配置文件（及可选内容文件）为 JSON，可下载留存。备份文件为纯 JSON，含每文件的 path / sha / content，便于人工核对与版本回溯。

      说明：「生成备份」仅读取并打包，不会改动任何线上文件；下载的 JSON 可在左侧「数据恢复」中写回 GitHub。内容文件（文章 / 动态 / 页面 / 图库）体积较大，默认不纳入备份，如需连同内容一起备份可勾选下方选项。

      🔄 数据恢复

      将此前在「数据备份」中下载的 JSON 备份写回 GitHub，覆盖现有线上文件以实现回滚。请先选择本地备份文件，确认内容无误后再执行恢复。

      说明：「执行恢复」将逐文件用备份中的 content 提交到 GitHub（保留原 sha 以便冲突检测），覆盖现有配置——此操作会覆盖线上文件，建议先到「数据备份」下载当前配置留存。恢复完成后 GitHub 将自动重新部署。
