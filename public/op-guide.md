# Firefly 内容管理系统 · 操作说明

欢迎使用 Firefly 内容管理系统（Firefly-Admin）！本系统是 Firefly 博客的**可视化管理后台**，直接通过 GitHub API 远程管理博客的内容与配置：**保存即提交 GitHub，站点自动重新部署**，无需服务器、无需命令行操作。

本说明按使用场景组织，建议先阅读「快速上手」，再按需查阅各板块的详细操作。

## 一、界面导航

登录后台后，左侧导航栏分为三个板块（默认均处于折叠状态，点击板块标题可展开 / 收起）：

- **内容管理** —— 日常内容维护：文章内容、我的动态、页面信息、图库素材
- **站点配置** —— 博客外观与功能设置：基础配置、功能配置、页面配置、扩展功能
- **数据安全** —— 一键备份恢复博客数据

展开任一板块后，点击其中的菜单项即可进入对应功能。

## 二、快速上手

第一次使用，按以下三步即可完成第一次内容发布：

1. **登录后台**：打开后台地址，输入管理员密码登录。登录状态保留 7 天，期间无需重复输入。
2. **进入板块**：在左侧「内容管理」点击「文章内容」，再点击右上角 **＋ 新建**。
3. **编辑并保存**：填写标题与正文后，点击顶部 **保存** 按钮，等待上传即完成发布。

**保存即部署**：点击保存后，系统会先将文件上传到 GitHub，成功后自动触发站点重新部署，通常 1 分钟左右站点即可看到更新。请务必等待保存完成的提示再离开页面。

## 三、内容管理

### 3.1 文章内容

文章存放于博客的 `src/content/posts` 目录，支持 `.md` 与 `.mdx` 两种格式，也支持子目录分类管理。

- **新建文章**：点击工具栏 **＋ 新建**，填写文件名（不填则自动生成）。文件名后缀由右侧下拉框统一管理，无需手动输入。
- **编辑文章**：点击列表中的文章即可进入编辑器。编辑器支持 **富文本 / 源代码** 两种模式切换：富文本模式所见即所得，源代码模式直接编辑 Markdown。
- **内容与文章信息 Tab 切换**：编辑器上方有「内容」与「文章信息」两个标签页，默认停在「内容」；点击「文章信息」可填写结构化字段，包括：
  - 基础信息：标题、发布日期、更新日期、自定义 slug、语言、作者
  - 摘要与封面：文章描述、封面图
  - 分类与标签：标签（逗号分隔）、分类
  - 加密保护：访问密码与密码提示（开启后文章需密码才能查看）
  - 发布选项：草稿（读者不可见）、置顶、允许评论
  - 高级：许可证名称 / 链接、来源链接
- **子目录管理**：工具栏 **＋ 新建分类** 可在当前目录下创建子文件夹；通过面包屑或 **↑ 上级** 按钮返回上层目录。
- **列表批量操作**：勾选文件左侧复选框可多选，点击 **🗑 批量删除** 一次删除多篇；勾选 **全选** 可选择当前列表全部文件。
- **单文件操作**：列表每行提供 **编辑 / 重命名 / 删除** 按钮；桌面端右键文件可呼出更多操作菜单，移动端长按文件弹出操作表。

**提示**：文章板块下的图片子目录（images / guide 等）统一由图库素材集中管理，文章列表不显示。

### 3.2 我的动态

动态用于发布短内容（近况、随想等），文件名自动按「年-月-日-时分秒」生成，**无需手动填写文件名**。

- 新建动态后，只需填写：发布时间、地点、正文内容
- 动态同样支持编辑、重命名、删除与批量删除

### 3.3 页面信息

单页内容（如「关于我」「友情链接」「留言页」）存放于 `src/content/spec` 目录，以**整份 Markdown 文件**方式编辑：

- 列表中以中文显示页面名称（如 about.md 显示为「关于我」），悬停可查看原始文件名
- 点击进入后直接编辑完整 Markdown 内容，可自行维护文件内的 Frontmatter 字段

### 3.4 图库素材

图库集中管理文章引用的图片资源（文章板块下各子目录的图片），按**分类目录**组织：

- 每个分类对应 `src/content/posts` 下的一个子文件夹（如 `123456`、`abcdefg`）；点击某个分类可进入并查看该分类下的图片
- 顶部 **＋ 新建分类** 可在 `src/content/posts` 下新建一个分类子目录
- 图片以**宫格缩略图**展示，点击缩略图可放大预览
- 鼠标悬停卡片右上角出现 🗑 按钮，可删除对应图片
- 图片文件不提供编辑功能，仅支持删除
- 上传图片到指定分类时，使用底部「资源上传」面板的文件夹选择器（详见第五章）

## 四、站点配置

站点配置全部采用**可视化结构化编辑**：参数名锁定、只允许修改值，保存即提交 GitHub。少数配置若包含暂不支持的语法而无法解析，会自动回退为源码编辑器（顶部出现橙色提示），仍可编辑保存。四个配置菜单分别管理不同类别的配置：

### 4.1 基础配置

站点最核心的身份与外观配置：

- 站点 Logo（图片上传）、作者头像（图片上传）
- 站点基础配置：站点名称、语言、关键词、描述等
- 导航栏配置：管理导航栏自定义链接分组与子链接
- 页脚配置：页脚参数 + 页脚内容（富文本）一体化编辑
- 背景壁纸、侧边栏布局、公告、用户资料

### 4.2 功能配置

博客功能模块配置：字体、评论系统、封面图、音乐播放器、PlantUML 图表、Mermaid 图表、统计分析。

### 4.3 页面配置

独立页面相关配置：友链、相册、打赏、书签导航（书签导航支持以分组 / 书签列表形式新增与编辑）。

### 4.4 扩展功能

进阶功能配置：动画特效、许可证、看板娘、动态页面、代码高亮、显示设置面板。

### 4.5 高级模式（源码编辑）

每个可视化配置面板的右上角都提供 **⚙ 高级模式** 按钮，供熟悉配置结构的开发者直接以源代码形式修改：

1. 点击 **⚙ 高级模式**，会先弹出**风险确认提示**：开启后将直接以源代码形式编辑、绕过表单校验，若因操作不当导致站点异常需自行承担风险。
2. 在源码模式下，点击 **← 返回可视化编辑** 可重新解析源码并回到可视化表单；若源码能被正确解析，表单会反映你改动的字段。

提示：高级模式与「4.1–4.4 中因解析失败自动回退的源码视图」外观一致；区别在于高级模式是开发者**主动**开启，而非系统自动回退。

### 配置编辑通用规则

- **下拉选择**：带枚举值的字段自动渲染为下拉框，只能选择预设值（部分字段支持「自定义…」输入）
- **数组增删**：如站点关键词等数组字段，可自由添加、删除、编辑每一项
- **保存**：每个配置面板右上角都有 **💾 保存** 按钮，保存即提交 GitHub 并触发自动部署

## 五、上传资源

每个内容板块（文章内容 / 我的动态 / 页面信息 / 图库素材）的列表页**底部都带有独立的「资源上传」面板**，资源会直接上传到**当前板块对应目录**，各板块互不干扰：

- **面板标题** 随板块变化，例如「图库素材 · 资源上传」，一眼可知当前上传到哪个板块。
- 面板**默认展开**，可直接看到文件夹选择器；顶栏 **📤 上传资源** 按钮也可快速展开并聚焦面板。
- **选择文件夹**：面板顶部「上传到文件夹」下拉框，会列出当前板块下的子目录（图库素材列出 `src/content/posts` 下的各个分类目录，如 `123456`、`abcdefg`）。选择某子目录后，下方提示会实时显示「自动上传到 <目录>」。
- **上传文件**：拖拽文件到虚线区域，或点击 **＋ 选择文件** 选取文件（支持多选）。选定后文件**自动上传**到所选文件夹，并在列表里显示上传进度与结果，无需额外点击保存。

提示：切换板块时，上传面板会重置为「根目录（当前板块）」，并重新列出该板块的子目录；图库素材的分类目录可在图库页面通过「＋ 新建分类」创建（见 3.4）。

## 六、注意事项

- 保存后请等待「已保存，GitHub 自动部署中」提示，站点更新通常需要约 1 分钟
- 配置类内容不支持批量操作（列表不显示复选框）
- 删除操作不可恢复，请谨慎操作；批量删除前会再次确认
- 使用 **⚙ 高级模式** 直接改动配置源码时请格外谨慎：错误的语法可能导致该配置无法解析（系统会回退为源码视图，需手动修正后才能恢复可视化表单）
- 请妥善保管管理员密码，不要将其写入代码仓库或分享给无关人员
- 本系统允许二次开发与商业使用，但必须保留版权信息与原作者署名，详见「关于」页

## 七、常见问题

**Q：保存后站点没有变化？**

A：先确认页面是否出现「已保存」提示；站点部署通常需要约 1 分钟，可稍后刷新页面查看。

**Q：文章为什么不显示？**

A：检查「文章信息」中「草稿」是否被勾选，草稿对读者不可见。

**Q：图片无法上传？**

A：确认文件为常见图片格式（png / jpg / gif / webp / svg 等），且网络连接正常。

**Q：配置修改后站点显示异常？**

A：配置字段大多为枚举下拉，请确认字段值在允许范围内；若使用 **⚙ 高级模式** 手工改动过源码，请确认语法正确，否则可对照原始配置恢复。
